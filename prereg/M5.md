## 1. Formal Mathematical Hypotheses

### Prediction P_M5_1: The Invariant Thinking Core Under World Randomization
Let $\mathcal{W} = \{W_1, W_2, \dots, W_M\}$ be a set of $M$ synthetic worlds where:
1. Each world $W_m$ possesses an independent, identically distributed set of factual triples:
   $$I(F_m; F_{m'}) = 0 \quad \forall m \neq m'$$
2. All worlds share an identical set of procedural algorithmic skills $S = \{s_1, \dots, s_k\}$ with invariant computational grammar.

Under joint Minimum Description Length factorization with architecture $\theta_m = \theta_{\text{core}} + \text{Mem}_m$ and objective:
$$\mathcal{L}_{\text{MDL}} = \sum_{m=1}^M \mathcal{L}_{\text{NLL}}(W_m; \theta_{\text{core}}, \text{Mem}_m) + \beta \left[ \widehat{\text{DL}}(\theta_{\text{core}}) + \sum_{m=1}^M \widehat{\text{DL}}(\text{Mem}_m) \right]$$

The physical description length of the shared thinking core $\text{DL}^*(\theta_{\text{core}})$ remains bounded and invariant with respect to the number of worlds $M$:
$$\lim_{M \to \infty} \frac{\partial \ln \text{DL}(\theta_{\text{core}})}{\partial \ln M} = 0$$

Specifically, in a log-log regression $\ln(\text{DL}(\theta_{\text{core}})) = \alpha_0 + \gamma_{\text{core}} \ln(M)$, the scaling exponent satisfies:
$$\gamma_{\text{core}} \le 0.20 \quad (\text{upper 95\% Bootstrap CI})$$

### Prediction P_M5_2: Linear Factual Memory Scaling
The physical description length of the per-world memory module $\text{DL}^*(\text{Mem}_m)$ scales strictly linearly with the factual information content $I_{\text{facts}}(W_m)$:
$$\text{DL}^*(\text{Mem}_m) = \frac{I_{\text{facts}}(W_m)}{\kappa_m} + \delta_{\text{mem}}$$
With coefficient of determination $R^2 \ge 0.95$ and slope satisfying the physical lower bound $\kappa_m \le 3.0$ b/p ($\text{DL}(\text{Mem}_m) \ge I_{\text{facts}} / 3.0$).

### Prediction P_M5_3: Decisive Transfer to Unseen Worlds
Given a thinking core $\theta_{\text{core}}^*$ converged under WRMF training across $M \ge 4$ worlds, when $\theta_{\text{core}}^*$ is frozen (`requires_grad=False`) and attached to a freshly initialized memory $\text{Mem}_{\text{unseen}}$ for a completely unseen world $W_{\text{unseen}}$, optimizing only $\text{Mem}_{\text{unseen}}$ achieves at least 95% of the end-to-end joint training accuracy:
$$\text{Transfer Ratio} = \frac{\text{Acc}(\theta_{\text{core}}^* + \text{Mem}_{\text{unseen}})}{\text{Acc}_{\text{joint}}(W_{\text{unseen}})} \ge 0.95$$

### Prediction P_M5_4: Null Control Structural Collapse
When procedural skills are randomized/shuffled across worlds such that no computational invariant is shared ($I(S_m; S_{m'}) = 0$), the MDL penalty forces the shared core to collapse toward zero functional capacity:
$$\frac{\text{DL}^*(\theta_{\text{core}}^{\text{null}})}{\text{DL}^*(\theta_{\text{core}}^{\text{true}})} \le 0.20 \quad (\ge 80\% \text{ structural description length collapse})$$

### Prediction P_M5_5: WRMF Parsimony Superiority over Post-Hoc Pruning
World-randomized MDL factorization extracts a more compact representation of algorithmic skills than single-world post-hoc compression:
$$\text{DL}_{\text{skill}}(\text{WRMF}) \le \text{DL}_{\text{skill}}(\text{M4 post-hoc})$$

## 3. Experimental Grid Specifications

- **World Regimes ($M$):** $M \in \{2, 4, 8, 16\}$ independent synthetic worlds.
- **Memory Architectures:**
  1. `LoRAMemory`: Rank-$r$ adaptation on linear projections ($r=4$).
  2. `PKMMemory`: Product-Key Memory / Key-Value Memory layer with top-$k$ routing ($k=2$).
  3. `EntityEmbeddingMemory`: Dedicated entity-relation embedding tables.
- **Facts per World:** $K \in \{64, 128, 256, 512\}$ entities $\times 6$ attributes ($I_{\text{facts}} \in [1536, 3072, 6144, 12288]$ bits).
- **Procedural Skills:** Algorithmic suite $\{S_1, S_2, S_3, S_5, S_6\}$ (Copy, Reverse, Sort, KV Lookup, ModAdd).
- **RNG Seeds:** 42, 43, 44.
- **Hardware Target:** Apple Silicon MPS.
