## 1. Formal Mathematical Hypotheses

### Prediction P1: The Additive Quanta Composition Law
The true description length $\text{DL}^*(M)$ of a neural network $M$ trained on a mixture of procedural algorithmic skills $S$ and declarative factual knowledge $F$ satisfies:

$$\text{DL}^*(M) = c_{\text{alg}} \sum_{s \in S} K(s) + \frac{I_{\text{facts}}}{\kappa} + \delta(N) + \eta \cdot I_{\text{interaction}}$$

Where:
- $K(s)$ is the algorithmic Kolmogorov complexity of skill $s$ measured via the minimal RASP program length in bits.
- $I_{\text{facts}} = K_{\text{ent}} \sum_{a=1}^6 \log_2 |V_a|$ is the Shannon information content of the ground-truth facts in bits.
- $c_{\text{alg}}$ is the universal program-to-neural weight conversion factor (bits of weight representation per bit of RASP program).
- $\kappa$ is the universal factual capacity constant (bits of fact stored per parameter/weight bit, prior expectation $\approx 2.0$).
- $\delta(N)$ is the structural baseline overhead of the neural architecture at parameter scale $N$.
- $\eta$ is the interaction coefficient governing cross-domain capabilities (e.g. relational queries over stored facts).

### Prediction P2: The Bounded Thinking Core (Skill Saturation)
As total parameter scale $N \to \infty$, the description length required to represent a fixed set of procedural skills $S$ saturates:

$$\lim_{N \to \infty} \frac{\partial \ln \text{DL}_{\text{skill}}}{\partial \ln N} = 0$$

Specifically, in a log-log regression $\ln(\text{DL}_{\text{skill}}) = \beta_0 + \gamma \ln(N)$, the scaling exponent $\gamma$ satisfies $\gamma \le 0.30$ (sub-linear saturation, unlike parameter count where slope = 1.0).

## 2. Competing Alternative Hypotheses (Ablation Models)

We evaluate the LEAN composition law against three standard competing models:

1. **Model A (Naive Scaling Law):**
   $$\text{DL}_{\text{naive}} = \beta_0 + \beta_1 N$$
   (The model assumes true representation size scales linearly with parameter count $N$, ignoring quantum structure).
2. **Model B (Multiplicative Entanglement):**
   $$\text{DL}_{\text{mult}} = \beta_0 + \beta_1 \left( I_{\text{facts}} \cdot \sum_{s} K(s) \right)$$
   (Assumes skills and facts cannot be factored orthogonally and create combinatorial parameter growth).
3. **Model C (Pure Memorization / No Skill Term):**
   $$\text{DL}_{\text{no\_skill}} = \beta_0 + \frac{I_{\text{facts}}}{\kappa}$$
   (Assumes networks are pure lookup tables and procedural skills have zero dedicated description length).
