## 1. Executive Protocol & Technological Objectives

Milestone M11 translates the **Priced-Quanta Equation v1** into a working compression technology and local inference architecture:
1. **Knapsack-Aware Compressor (KAC):** Bit allocation driven by value per bit:
   - High bit allocation (4-bit/8-bit) to skill-critical attention routing circuits (QKVO).
   - Aggressive low-bit allocation (2-bit/3-bit) to fact-heavy MLP matrices.
2. **Thinking Core + Retrieval Store:**
   - Compress the model down to its algorithmic core ($\le 1/5$ physical description length).
   - Offload factual memory to a fast local BM25 / vector retrieval index over Wikipedia facts.
3. **Apple Silicon Native MLX Inference:**
   - Measure tokens/sec (prefill and decode), peak memory footprint, and speedup on Apple Silicon M2.

## 3. Evaluation Protocol

1. **Target Models:**
   - Primary: `HuggingFaceTB/SmolLM2-360M` (361.8M params, LLaMA-GQA architecture).
   - Scaling & Cross-Validation: `EleutherAI/pythia-160m` and `EleutherAI/pythia-410m`.
2. **KAC Value-per-Bit Allocation:**
   - Protect attention projections ($W_q, W_k, W_v, W_o$) at higher bit precision ($4\text{b}/8\text{b}$).
   - Compress feed-forward MLP projections ($W_{\text{gate}}, W_{\text{up}}, W_{\text{down}}$) to $2\text{b}/3\text{b}$.
   - Exact physical mixed-precision accounting:
     $$B_{\text{exact}} = 16 \times N_{\text{unquant}} + \sum_l N_l \left(b_l + \frac{16}{g}\right)$$
3. **Retrieval Store Evaluation:**
   - Corpus: 1,000 verified factual passages from Wikipedia / Wikidata relations.
   - Index: Fast BM25 ranker with BM25Okapi scoring.
   - Head-to-Head Comparison:
     1. Uncompressed Full Model (FP16)
     2. Compressed Thinking Core alone (no retrieval)
     3. Compressed Thinking Core + BM25 Retrieval
     4. Dense small model baseline of equivalent total size
