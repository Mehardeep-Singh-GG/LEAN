## 1. Formal Mathematical Hypotheses

### Prediction P_M6_1: Decompilation Fidelity Bound (Algorithmic Equivalence)
For any procedural skill circuit $s \in \{S_1, \dots, S_9\}$ isolated in the Thinking Core $\theta_{\text{core}}$, there exists an explicit, discrete Transformer Program / RASP program $\mathcal{P}_s$ such that on held-out test inputs $D_{\text{test}}^{(s)}$:
$$\text{Fidelity}(\mathcal{P}_s, \theta_{\text{core}}) = \frac{1}{|D_{\text{test}}^{(s)}|} \sum_{x \in D_{\text{test}}^{(s)}} \mathbf{1}\left[\mathcal{P}_s(x) == \arg\max f_{\theta_{\text{core}}}(s, x)\right] \ge 0.990$$
for at least 6 of the 9 canonical skills ($\ge 66.7\%$).

### Prediction P_M6_2: Universal Compilation Constant Invariance ($c_{\text{alg}}$ Constant)
The empirical ratio between the physical neural description length $\text{DL}_{\text{neural}}(s)$ (measured via Ruler A: 4-bit RTN + arithmetic entropy coding of active circuit parameters) and the algorithmic program complexity $K_{\text{program}}(s)$ (measured via Ruler C in RASP tokens/bits):
$$c_{\text{alg}}(s) = \frac{\text{DL}_{\text{neural}}(s)}{K_{\text{program}}(s)}$$
is approximately invariant across procedural skills, exhibiting a Coefficient of Variation (CV):
$$\text{CV}(c_{\text{alg}}) = \frac{\sigma(c_{\text{alg}})}{\mu(c_{\text{alg}})} \le 0.30 \quad (\le 30.0\%)$$

### Prediction P_M6_3: Programmatic Description Length Boundedness
The programmatic complexity $K_{\text{program}}(s)$ measured by Ruler C provides a finite, non-trivial upper bound on the algorithmic Kolmogorov complexity of the neural circuit:
$$K_{\text{bits}}(\mathcal{P}_s) = |\text{Tokens}(\mathcal{P}_s)| \cdot \log_2 |V_{\text{grammar}}|$$
where $|V_{\text{grammar}}| = 64$ primitives, satisfying $K_{\text{bits}}(\mathcal{P}_s) \le \text{DL}_{\text{neural}}(s)$ for all decompiled skills.

### Prediction P_M6_4: Symbolic Closed-Form Recovery for Arithmetic and Syntax Circuits
For non-trivial numerical and syntactic sub-circuits ($S_6$ modular addition and $S_7$ Dyck-2 bracket validation), the continuous weights distill into exact symbolic closed-form equations:
- $S_6$: $f(a, b) = (a + b) \pmod p$
- $S_7$: $f(\text{seq}) = \mathbf{1}\left[\forall t \le L: \sum_{i=1}^t \delta_i \ge 0 \;\land\; \sum_{i=1}^L \delta_i = 0 \;\land\; \text{PairsMatch}(\text{seq})\right]$
achieving 100% exact numerical agreement over their domains.

### Prediction P_M6_5: Multi-Seed Algorithmic Stability
The decompiled RASP programs and execution fidelities are robust across independent SGD training runs (seeds 42, 43, 44), demonstrating that neural SGD consistently discovers the same canonical algorithmic equivalence class.
